关于我

从一个问题出发，
做出能用的作品。

我是雷子恒，正在持续探索 Python 与 Web 应用开发。我喜欢从学习和生活中的具体问题出发，用代码把想法做出来。在项目实践中，我关注功能是否实用，也在意页面是否清楚、操作是否顺手。

我的项目 CampusMind 是一个校园智能知识库，支持文档导入、自然语言检索和原文引用展示。围绕这个项目，我实践了 FastAPI 接口开发、SQLite 数据管理与前端交互，逐步理解一个应用从数据到页面的完整流程。

我希望继续通过实际项目积累经验，把每一次遇到的问题、做过的尝试，变成下一次进步的起点。欢迎与我交流开发经验、项目想法，也期待参与有价值的合作。

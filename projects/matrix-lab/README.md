# Matrix Lab 矩阵实验室

面向矩阵课程的交互工具。支持2×2、3×3的行列式、求逆、转置、乘法和线性方程组，并用SVG展示二维单位正方形在A作用下的像。

## 运行

在仓库根目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000/projects/matrix-lab/`。页面使用原生ES模块，需要HTTP服务，不建议直接双击HTML。运行无需安装npm依赖。

## 结构

- `core.js`：纯计算函数及输入验证；Gauss–Jordan消元使用部分选主元，降低小主元带来的数值误差。
- `app.js`：读取输入、显示结果、渲染步骤、用SVG绘制二维变换。
- `index.html`：语义化页面及输入控件，样式共享自 `../labs.css`。
- `../../tests/labs.test.js`：包含已知解、求逆后乘回单位矩阵、主元交换、奇异矩阵、数值尺度与输入错误检查。

## 演示建议

1. 默认A=[[2,1],[1,1]]，展示det=1和逆矩阵。
2. 切换为AX=b，默认b=(3,2)，结果X=(1,1)。
3. 点击旋转90°示例，说明矩阵两列就是基向量的像。
4. 点击奇异示例，图形压成直线、det=0，并拒绝求逆。
5. 切换3×3，再查看消元步骤。

## 边界

使用JavaScript双精度浮点数、显示8位有效数字，不做分数/符号求解。输入绝对值限制为10⁶。数值上接近奇异会拒绝求逆；不能将该行为当成严格的符号奇异性证明。图形仅展示二维线性变换，采用自动缩放，不包含三维渲染或特征值功能。编辑后点击计算才更新结果。

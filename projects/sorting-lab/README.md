# Sort Lab 排序可视化实验室

比较冒泡、插入和选择排序。支持自定义3–32项整数、随机输入、播放/暂停、单步、速度调整、重置，以及比较/交换次数。

## 运行

从仓库根目录启动 `python3 -m http.server 8000`，访问 `http://localhost:8000/projects/sorting-lab/`。无需npm运行依赖。因使用ES模块，请通过HTTP打开。

## 实现

`core.js` 中的 `buildTrace()` 独立于DOM：复制输入，执行指定算法，每步保存数组快照、动作类型、涉及下标及累计计数。`app.js` 只管理播放状态、光标和渲染。

插入排序采用相邻交换版本，方便与其他算法使用同样的比较/交换统计。暂停不会重新计算，更换算法从相同原始数组重新开始；页面切到后台会暂停。输入校验失败时保留上一组图表，并显示错误。

## 对比场景

- 已排序：冒泡提前结束，只做n−1次比较；选择仍做n(n−1)/2次比较。
- 逆序：观察冒泡和插入的交换次数。
- 重复数值：验证相等时冒泡/插入不交换，理解稳定性；图中未为重复项添加身份标记，不单凭柱状图判断稳定性。

## 复杂度与限制

三种算法平均/最坏时间为O(n²)，算法自身辅助空间O(1)。用于回放的快照轨迹额外消耗最坏O(n³)空间，所以限制最多32项。计数只统计比较和交换，不是毫秒级性能基准。排序范围为1–99整数，未实现大数组、后端存储或网络同步。

运行仓库根目录的 `npm test` 可检查排序结果、输入不变性、快照独立性、操作计数、重复数据和最大长度输入。

# 项目演示与讲解准备

本次新增Matrix Lab和Sort Lab，保留原有CampusMind介绍和链接。以下是演示顺序和需要理解的技术点，不代表学校评分标准，也不替代对代码的理解。

## 五分钟演示

1. 约30秒：从首页打开两个新项目，说明它们分别解决数学计算理解和排序过程观察的问题。
2. 约90秒：矩阵默认求逆→切换方程组→旋转示例→奇异示例。解释为什么det=0时不能求逆。
3. 约90秒：排序用 `5,4,3,2,1` 单步两次、播放、暂停；再用 `1,2,3,4,5` 对比冒泡和选择的比较次数。
4. 约60秒：打开core.js，解释计算与界面分离；展示测试命令及真实输出。
5. 约30秒：说明现有限制及下一步改进，不把尚未实现的功能当成完成项。

## 应当能回答的问题

### 矩阵

- 为什么先判断输入是否合法？为什么空输入不能默认为0？
- 求逆为什么交换主元行？部分选主元能减少什么数值问题？
- 为什么AB与BA不同？如何用旋转与拉伸举例？
- 图中如何从矩阵两列得到单位正方形四个像点？
- “近奇异”阈值与严格det=0有什么区别？浮点数有什么限制？

### 排序

- 为什么把算法输出设计成一组步骤，而不是把定时器写进算法？
- 如何保证暂停、单步和调速不会同时创建多个定时器？
- 为什么冒泡和插入在已有序时更快，而选择比较次数不变？
- 稳定性是什么意思？为什么选择排序可能改变相等元素的相对顺序？
- 算法空间O(1)，为什么本演示的回放轨迹却可能占O(n³)空间？

## 实际验证

在根目录运行 `npm test`。测试覆盖求逆、方程组、主元交换、奇异输入、排序结果与操作次数等。自动测试证明的是这些已列出的性质；界面布局、点击流程和可访问性还需通过浏览器检查。
